模型测速 · 列表内跑分（v2）

在「选择超分模型」浮层里加三个按钮：一键测试全部 / 测试选中模型 / 仅测试当前分组。测完把每个硬件（多 GPU 各一条）的耗时写在模型名称下方。

演示控制

本轮定稿（按你的 6 条）

  • 不可用硬件只说一次：标在工具条下的硬件图例里，行内不重复。
  • 不暴露测试次数：固定 192×192 单块输入（GPU 3 次取中位数，CPU/NPU 1 次）， 界面不出现次数。
  • 关闭浮层 = 取消，已完成结果保留；再次打开时浮层顶部弹出「继续测试」提示。
  • 测试结束恢复原模型（含后端偏好），不会替你切模型。
  • 耗时结果始终保留：切筛选、关浮层、切页都不丢；重测只覆盖被测的那几个模型。
  • 新增「仅测试当前分组」：只测当前筛选分组；在「全部」下禁用。

布局：工具条两行

  • 第 1 行：三个按钮；运行时最右侧出现「停止」。
  • 第 2 行：状态文字（左）+ 2px 进度条（右）。三个按钮一行放不下状态， 所以状态独占第二行——这是相对上一版 demo 的唯一结构性改动。
  • 第 3 行：硬件图例（可用/不可用只写一次）。

字段契约

字段位置与规则
模型名第 1 行，完整显示不省略
完整 ID第 2 行，等宽 10px onnx 文件名
耗时第 3 行，等宽 10.5px；每个物理 GPU 一条 + NPU + CPU； 最快的用主色；失败写原因
体积 / 状态右侧两列不变（当前使用 / 已选 / —）

行状态

状态表现
未测试没有第 3 行，行高 52px
测试中当前硬件写「测试中…」，行高 68px
完成逐硬件耗时，最快用主色
失败该硬件写原因（红），其余照常
取消已完成的行保留；未跑的无第 3 行，并在下次打开时提示继续

演示怎么做

  • 点「一键测试全部」→ 运行中可点「停止」，或点右上角 × 关闭浮层（= 取消）。
  • 关闭后屏幕上出现「重新打开浮层」；再打开会看到顶部「上次测试未完成 23/46」提示。
  • 提示里点「继续测试」只跑剩下的模型；点「忽略」保留现有结果并收起提示。
  • 切换筛选后「仅测试当前分组」才可用（在「全部」下禁用）。

待确认（仅剩 2 条）

  • 结果写不写盘：demo 只存在页面内存；C++ 里我打算写进 ui.ini （带硬件指纹，换显卡/换设备自动丢弃），这样重启也“始终保留”。
  • 全量耗时：46 模型 × 3 硬件，真机预计 3~6 分钟；「仅测试当前分组」就是为这个加的， 若仍嫌长，可以再限制“每模型只测 1 个 tile”（已经是 1 个）。
